# 🦠 Covid Dashboard Analysis

## 📌 Introduction
This project provides real time analysis of **COVID-19 data** using **Excel**.  
The dashboard was created after cleaning and transforming the dataset with **Power Query** and then visualizing trends such as **confirmed cases, recoveries, deaths & rates**.  
The purpose of this project was to **data wrangle, dashboard design, and derive business insights** from real-world health data.

---

## 📊 Excel Dashbaord Report
* The **Dashboard view report** shows an overview of COVID-19 confirmed cases, recoveries, and deaths across different regions.
* The analysis has slicers to filter Dates like Year, Month and Day.

👉 Example visuals include **cards, bar charts, line graphs, and a table**.

## 🔎 Insights and Findings
* Trends in **confirmed cases, recoveries, and deaths** over time.  
* Comparative analysis of regions/countries most affected.  
* Patterns in recovery vs. fatality rates.  
* Discovered top 5 countries with the highest confirmed cases with the US leading the way with 1.7 million in the year 2020
* Keyed in on 3 KPIs in confirmed cases
* Early outbreak phase → “Cases started rising slowly in March but accelerated in April through the year.
* Recovery trends → By Feb 2023, recoveries had overtaken new cases, with recovery rate improving from 45% to 80%.
* Mortality analysis → “The fatality rate stood at 3.11%, with the highest number of deaths recorded in December.”
